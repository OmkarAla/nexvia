# Data setup

Both projects use synthetic demo data by default. Real datasets are optional and must be fetched with your own Kaggle credentials. **No dataset is committed or redistributed.**

## Kaggle token

Store the token outside the repository:

```bash
mkdir -p ~/.kaggle
# paste the token from https://www.kaggle.com/settings/api
printf '%s' 'KGAT_...' > ~/.kaggle/access_token
chmod 600 ~/.kaggle/access_token
```

Or export `KAGGLE_API_TOKEN` in the shell / Colab secrets. Never put it in `.env`, a notebook, or a commit.

Verify:

```bash
kaggle competitions files -c ieee-fraud-detection
```

## Fraud — IEEE-CIS

Competition rules must be accepted on the Kaggle website first.

```bash
cd AIML-01
mkdir -p data/raw/ieee
kaggle competitions download -c ieee-fraud-detection -p data/raw/ieee
cd data/raw/ieee && unzip -o '*.zip' && rm '*.zip'
```

Files: `train_transaction.csv` (~683 MB), `train_identity.csv` (~27 MB), test equivalents. `data/raw/` is gitignored.

The committed demo path never needs this download:

```bash
make data      # synthetic
make train
make gnn
```

## Imaging — NIH ChestX-ray14 and MSD Spleen

- **NIH ChestX-ray14** — Kaggle mirror `nih-chest-xrays/data` (~42 GB). For Colab, stream a fixed subset from the HuggingFace mirror instead of downloading the full archive.
- **MSD Task 09 Spleen** — 41 training CT volumes, CC-BY-NC-SA. Fetch from the Medical Segmentation Decathlon and keep attribution; it is not committed.

```bash
# Example: check the Kaggle mirror without downloading the full archive
kaggle datasets files -d nih-chest-xrays/data
```

The imaging vertical slice uses the committed synthetic studies (`AIML-02/data/demo/`), so Orthanc and the viewer work offline.

## Colab

In Colab, use secrets rather than a notebook cell:

```python
from google.colab import userdata
import os
os.environ["KAGGLE_API_TOKEN"] = userdata.get("KAGGLE_API_TOKEN")
```

Checkpoints and small metric artifacts go to the repo's `reports/`; datasets and checkpoints stay out of git (GitHub Releases for weights).
